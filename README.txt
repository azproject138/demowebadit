NANU - Professional Welding & Fabrication Website

Isi:
- index.html
- css/style.css
- js/projects.js
- js/script.js

Cara menjalankan:
1. Ekstrak folder nanu.
2. Letakkan foto asli pada folder assets sesuai struktur.
3. Buka index.html langsung di browser.
